# 拼多多 AI 自动客服系统 — 设计文档

日期：2026-08-19
状态：草稿，待审阅

## 1. 背景与目标

商家需要在拼多多客服网页版（商家后台 `https://mms.pinduoduo.com/`）中，用 AI 自动处理买家咨询。要求：
- AI 生成回复后**全自动发送**到拼多多客服网页版
- 复用已登录的本地 Chrome，操作过程在客服网页版**实时可见**（相当于真人操作）
- 使用国内大模型（DeepSeek 等）生成回复
- 遇到敏感话题（退款/投诉/法律等）自动**转人工**，停止自动回复
- 本机 Windows 运行，无需额外监控面板

### 技术选型

| 层 | 选择 | 理由 |
|---|---|---|
| 语言 | Python 3.10+ | 生态好，Playwright/异步支持完善 |
| 浏览器控制 | Playwright + 复用本地已登录 Chrome (CDP) | 无需反复扫码，操作实时可见 |
| AI 服务 | DeepSeek API（可配置切换通义/豆包等） | 国内可用、中文好、性价比高 |
| 配置 | YAML 配置文件 + 环境变量 | 敏感信息（API Key）不入库 |
| 运行 | 本机 Windows，无独立监控面板 | 按需求，进度在客服页面本身可见 |

## 3. 核心组件

### 3.1 浏览器控制层 `browser_controller.py`
- 通过 CDP 连接本地已登录的 Chrome（`chrome --remote-debugging-port=9222`）
- 封装页面元素定位（会话列表、聊天窗口、输入框、发送按钮）
- 元素选择器集中在 `selectors.py` 配置，便于拼多多改版时单独维护
- 模拟真人操作：随机输入间隔、光标移动、点击前悬停

### 3.2 会话管理器 `session_manager.py`
- 维护每个顾客会话的状态（空闲/处理中/已发送/转人工）
- 轮询检测新消息（因拼多多无公开推送接口）
- 串行处理：同一时间只操作一个会话，避免多会话争抢页面焦点
- 会话冷却：回复后进入冷却期，避免重复回复

### 3.3 AI 回复引擎 `ai_reply_engine.py`
- 调用 DeepSeek API，支持切换其他国内模型
- 系统提示词注入角色设定 + 通用客服话术
- 返回结构化结果：`(回复文本 | 无法回答 | 转人工)`
- 失败自动重试 2 次

### 3.4 敏感词检查 `safety.py`
- 敏感词清单（退款、投诉、12315、法律、举报、差评威胁、辱骂等）
- 命中 → 转人工，不发送
- 规则可配置

### 3.5 配置 `config.yaml` + `.env`
- 入口 URL、轮询间隔、冷却时间、发送限速、每日限额
- API Key、模型名、知识库路径

## 4. 数据流（单条消息处理）

```
1. 轮询检测     Playwright 扫描会话列表，发现新消息/未读会话
2. 打开会话     自动点击该会话，读取聊天记录上下文
3. AI 生成      历史消息 + 话术库 → DeepSeek → 回复文本
4. 安全检查     敏感词过滤 → 命中则转人工，不发送
5. 自动发送     模拟真人输入（随机延迟）→ 点击发送
6. 更新状态     记录已发送，进入冷却，写日志
```

## 5. 会话状态机

```
┌────────┐  检测到新消息  ┌──────────┐  AI生成+安全检查  ┌────────┐
│  空闲   │ ────────────► │  AI处理中 │ ──────────────► │  已发送 │
└────────┘               └──────────┘                  └────────┘
                               │ 命中敏感词/无法回答/AI失败
                               ▼
                            ┌────────┐
                            │ 转人工  │  ← 标记待人工，停止自动回复
                            └────────┘
```

## 6. 安全机制（全自动模式关键防线）

- **敏感词转人工**：退款/投诉/法律/举报/辱骂等，命中即停
- **发送限速**：每会话冷却（默认 60s），全局节流（默认 每10s 最多1条）
- **每日限额**：每日最大自动回复数（可配置）
- **应急停止**：按 `Ctrl+C` 或发停止信号，立即暂停全部自动回复
- **不重发**：发送失败不自动重试，标记需人工检查，避免重复消息

## 7. 错误处理

| 场景 | 处理 |
|---|---|
| 元素定位失败 | 重试 + 重新探测选择器；仍失败则记录并跳过该会话 |
| AI API 失败 | 重试 2 次，仍失败转人工 |
| 发送失败 | 不重发，标记需人工检查 |
| 未登录/登录过期 | 停止并提示用户在 Chrome 中重新登录 |

## 8. 可扩展性（本期不做，保留接口）

- 店铺知识库文件（商品/物流/退换货规则）作为上下文注入
- 面板 + 人工接管模式
- 多店铺账号
- 手动触发回复
